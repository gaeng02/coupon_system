# Coupon System

## Requirments

### **기능 요구사항**
- 쿠폰 생성 및 관리
    - 관리자는 쿠폰을 생성하고 발급 가능한 수량을 설정할 수 있습니다.
    - 각 사용자는 특정 쿠폰을 1회만 발급받을 수 있습니다.
    - 쿠폰에는 유효기간이 설정됩니다.
- 쿠폰 발급
    - 설정된 수량만큼 쿠폰이 발급됩니다.
    - 사용자에게 중복 발급을 방지합니다. (사용자당 1회 발급 제한)
- 쿠폰 사용
    - 사용자는 발급받은 쿠폰을 사용할 수 있습니다.
    - 한 번 사용된 쿠폰은 재사용이 불가능합니다.
- 쿠폰 타입
    - 쿠폰 타입은 다음과 같은 종류(치킨, 피자, 햄버거, ...)가 존재합니다.
<br>

### **비기능 요구사항**
- 동시성 처리
    - 다수의 사용자가 동시에 쿠폰을 요청하더라도 시스템은 정상적으로 동작해야 합니다.
- 대규모 트래픽
    - 대량의 트래픽 환경에서도 시스템이 효율적으로 동작하도록 설계해야 합니다.
    - 쿠폰 발급 요청이 몰릴 경우에도 빠르게 처리될 수 있도록 시스템 성능을 최적화해야 합니다.
- 데이터 저장
    - 모든 쿠폰 정보 및 사용 이력을 데이터베이스에 저장해야 합니다.
    - 사용자별 쿠폰 발급 및 사용 이력을 체계적으로 관리해야 합니다.
<br>
